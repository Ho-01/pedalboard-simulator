## 차이 및 추가 사항

| 관련 ID | plan | 실제 구현 | 변경 사유 및 영향 |
| --- | --- | --- | --- |
| SIM-01 | 원 부품 모델 확보·출처 관리 | 122개 회로 부품, 65개 net과 BOM·source manifest·model registry를 전사했다. 반도체는 데이터시트 목표와 미측정 시험값을 포함한다. | 제조사 SPICE 모델과 실물 계측을 확보하지 못했다. 모델 상태를 시험용으로 유지하며 stock 음색 검증 완료로 취급하지 않는다. |
| SIM-02 | 원 가변저항의 taper와 endpoint | A taper 중간점은 15% 시험 가정이며 endpoint는 0.01 Ω으로 전개한다. | 원 ALPS 곡선과 접점 저항 미측정. 이 값은 확정 부품 특성이 아니다. |
| SIM-03 | 올바른 ON/OFF 동작점 | 래치의 초기 Newton 추정값을 제공하고 전원·기준·래치 전압을 별도 검사한다. | 대칭 래치 해가 수렴해도 요청한 상태가 아닐 수 있다. `.nodeset`은 강제 전압원이 아니며, 부적절한 상태는 오류로 처리한다. |
| SIM-05 | pin한 ngspice의 native/WASM | 같은 classic device subset과 compatibility patch를 사용한다. PWL 구간·breakpoint 탐색을 이진 검색으로 변경한다. | 전체 8초의 모든 입력 샘플을 유지하면서 검색 비용을 줄였다. 중복·역순 시간점은 원래 선형 검색으로 처리한다. 보간 산술·회로 방정식·solver 허용오차는 바꾸지 않았다. |
| SIM-05 | 재현 가능한 build | build cache 잠금과 고정 emsdk commit을 사용한다. | 중복 build의 산출물 충돌을 막고 툴체인 버전을 추적한다. 구조체 header 변경 후에는 관련 소자 객체를 전부 다시 빌드해야 한다. |
| SIM-05 | WASM 메모리 한도 | 초기 64 MiB, 필요 시 최대 1 GiB까지 증가한다. | 전체 8초 ON 결과를 저장할 때 최초 512 MiB 한도가 부족했다. 수치 정확도·전체 입력·solver 옵션을 유지하고 메모리 한도만 조정했다. 기본 ON 시험의 실제 heap은 571 MiB다. |
| SIM-06 | node/branch probe | 입력·출력과 두 증폭단 전압 probe를 제공한다. | branch current를 반환하는 공개 경로는 아직 구현하지 않았다. |

| time step refinement와 재표본화 | 성공, 시험 조건에 한정 | FIR 통과·저지 대역 단위 검사와 full circuit 4×/8× 비교 통과. 220 Hz·50 mV·노브 5·ON·0.1초 상대 RMS 0.00304%. 전체 amplitude·장시간 aliasing의 포괄적 보장은 아니다. |
| 부품 변경 공통 계산 경로 | 성공 | R9를 6.8 kΩ에서 13.6 kΩ으로 바꾼 동일 generator·solver의 출력 변화 21.2%. |
