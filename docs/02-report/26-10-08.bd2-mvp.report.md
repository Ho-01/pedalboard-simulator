| BD2-06 | 계산 상태 안내 | 페달이 있을 때 첫 회로 계산은 기기에 따라 몇 분이 걸릴 수 있다고 표시하고, 빈 작업 공간에서는 원본 데모를 바로 재생할 수 있다고 표시한다. | 실제 검증에서 전체 8초 계산에 분 단위 시간이 걸렸다. 계산을 기다릴지 판단할 수 있도록 안내를 구체화했다. |
| BD2-07 | 접을 수 있는 입력·출력 파형 | 두 증폭단 전압 선택도 추가했다. | 동일 계산의 probe 결과를 확인하기 위한 작은 확장. 내부 부품 편집기는 포함하지 않는다. |
| BD2-08 | 반복 재생·정지와 중복 source 방지 | 반복 모드 변경 때 현재 재생 위치에서 source를 다시 만든다. | 여러 회전 후 반복을 해제해도 현재 위치와 정지 경계를 일치시킨다. source는 한 번에 하나만 활성화된다. |
| BD2-09 | 실제 재생 생명주기 검사 | 브라우저 테스트가 wall clock 대신 AudioContext의 진행 시간을 기다린다. | 부하가 큰 검증 VM에서 오디오 clock이 느리게 진행되어 고정 9.2초 대기만으로는 한 회전 재생을 보장할 수 없었다. 앱의 시간을 임의로 빠르게 만들지 않았다. |
