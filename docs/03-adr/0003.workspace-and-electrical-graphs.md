# ADR-0003: 작업 공간과 전기적 연결을 구분

- 상태: 제안 — 그리드 바탕과 프레임을 구분하는 요구는 사용자 리뷰에서 확정, 구체적인 이름·구조는 검토 대상
- 작성일: 2026-10-08
- 관련 문서: [용어와 데이터 구조](../04-architecture/domain-model.md)

## 배경

이후에는 페달보드 프레임도 이동하고, 그 위에 여러 페달을 놓고, 케이블로 페달을 연결한다. 그리드 바탕과 페달보드 프레임을 모두 보드라고 부르면 객체의 역할이 섞인다.

## 제안

그리드 바탕을 **작업 공간(Workspace)**으로 부른다. 프레임, 페달 인스턴스, 패치 케이블은 그 위의 별도 객체다. 페달 내부 회로의 배선도 별도의 CircuitDocument에서 관리한다.

화면 위치, 프레임 소속, 페달 간 연결, 내부 회로 배선을 구분한다. 오른쪽에 놓인 페달이 자동으로 다음 신호 순서가 되지 않는다. 프레임은 기본적으로 기계적 배치 객체이며 전기적 노드를 만들지 않는다.

## 결과

프레임을 이동할 때 소속 페달의 상대 위치를 유지할 수 있다. 다른 프레임이나 공간으로 이동해도 전기적 연결은 사용자가 케이블을 바꾸기 전까지 유지된다. 케이블을 연결하면 실제 페달 입출력 port를 결합해 회로 전체를 계산할 수 있다.

후속 frame·routing·회로 편집 UI는 각각 plan을 작성한다. 이번에는 이 경계를 데이터 구조에 반영한다.
