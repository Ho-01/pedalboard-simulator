## 이번 구현

1. [Git·배포 기반](01-plan/26-10-08.repository-and-deployment.plan.md): 개발 가능한 최소 프로젝트와 원격 서버 배포 경로를 먼저 준비한다.
2. [BD-2 회로 시뮬레이션](01-plan/26-10-08.bd2-circuit-simulation.plan.md): 기준 회로와 부품 모델을 정리하고 native·브라우저 계산 및 파형·실물 검증을 진행한다.
3. [BD-2 1차 화면·청취](01-plan/26-10-08.bd2-mvp.plan.md): 실제 회로 계산 결과를 페달 배치·노브·데모 청취 화면에 연결한다.

세 plan 모두 2026-10-08 사용자 승인을 받았다. 구현 결과·차이·검증 및 미수행 항목은 [report 목차](02-report/README.md)를 따른다. 회로의 수치 검증과 실물 음색 검증은 별도로 관리한다.

2026-10-08 사용자 리뷰를 반영해 그리드 바탕을 Workspace로 구분하고, 첫 오디오 제안을 실제 회로 시뮬레이션으로 수정했다. [용어·데이터 구조](04-architecture/domain-model.md)와 [전체 구조](04-architecture/overview.md)를 함께 읽을 수 있다.

ADR 상태는 `제안`, `채택`, `대체됨`으로 구분한다. 사용자 요청으로 이미 정해진 개발 절차는 채택 상태이며, 첫 구현의 기술 스택·배포·계산 후 청취 설계는 채택 상태다.
